# Implemented Features


## FR003: View and edit profile for customer
The system must allow a customer to view and edit their profile. Edits save without re-entering the password and persist after reload.
**Status: Implemented**

## FR004: Manage saved payment methods for customer
The system must allow a customer to manage saved payment methods. Saved cards display only the last 4 digits, and add and remove work without exposing full card data.



## FR001: Register as a customer
The system must allow a new customer to create an account with full name, email, and password. The account stays inactive until the emailed confirmation link is used.
**Status: Implemented**
